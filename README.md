# Neo Mantle

An unofficial **Minecraft NeoForge** port of **Mantle** by SlimeKnights. This port is an actively maintained project to keep Tinkers' Construct up-to-date with the latest Minecraft versions!

Neo Mantle is a library/dependency mod & is **required by [Neo Tinkers](https://github.com/vancevoj/neotinkers)** and does little on its own.

Full content credit for the mod goes to SlimeKnights. I take no credit for any of the original work. This project is in no way endorsed by or affiliated with SlimeKnights.
