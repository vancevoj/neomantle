# Neo Mantle

**Neo Mantle** is a **Minecraft NeoForge** port of **Mantle** by SlimeKnights, specifically built to support Neo Tinkers'. This port is an actively maintained project to keep Tinkers' Construct up-to-date with the latest Minecraft versions!

Neo Mantle is a library/dependency mod & is **required by [Neo Tinkers'](https://github.com/vancevoj/neotinkers)**.

Full content credit for the mod goes to SlimeKnights. I take no credit for any of the original work. This project is in no way endorsed by or affiliated with SlimeKnights.

## Download

Pick your Minecraft version and download **both jars** (Neo Mantle and Neo Tinkers'). Each link opens the newest release; grab the jar listed for your version (not the `-sources` one). Jars from different versions do not mix.

### Minecraft 1.21.1

Needs NeoForge 21.1 and Java 21.

| Mod | Download | Grab this jar |
|---|---|---|
| **Neo Mantle** | [Latest release](https://github.com/vancevoj/neomantle/releases/latest) | `NeoMantle-1.21.1-...jar` |
| **Neo Tinkers'** | [Latest release](https://github.com/vancevoj/neotinkers/releases/latest) | `NeoTinkers-1.21.1-...jar` |

<br>

### Minecraft 26.3
