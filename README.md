# Neo Mantle

An unofficial **Minecraft NeoForge** port of **Mantle** by SlimeKnights. This port is an actively maintained project to keep Tinkers' Construct up-to-date with the latest Minecraft versions!

Neo Mantle is a library/dependency mod & is **required by [Neo Tinkers'](https://github.com/vancevoj/neotinkers)** and does little on its own.

Full content credit for the mod goes to SlimeKnights. I take no credit for any of the original work. This project is in no way endorsed by or affiliated with SlimeKnights.

## Download

Pick your Minecraft version and download **both jars** (Neo Mantle and Neo Tinkers') from that version only. Jars from different versions do not mix. The links always give you the newest full release.

### Minecraft 1.21.1

Needs NeoForge 21.1 and Java 21.

| Mod | Download |
|---|---|
| **Neo Mantle** | [NeoMantle-1.21.1.jar](https://github.com/vancevoj/neomantle/releases/latest/download/NeoMantle-1.21.1.jar) |
| **Neo Tinkers'** | [NeoTinkers-1.21.1.jar](https://github.com/vancevoj/neotinkers/releases/latest/download/NeoTinkers-1.21.1.jar) |

Release notes: [Neo Mantle latest](https://github.com/vancevoj/neomantle/releases/latest), [Neo Tinkers' latest](https://github.com/vancevoj/neotinkers/releases/latest)
